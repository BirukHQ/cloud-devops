
 Week 1 - Linux Hands-on Lab

 Overview
This lab introduces fundamental Linux commands and filesystem operations used in cloud computing and DevOps.

 Tasks Completed

- Created project directories.
- Created and edited a text file.
- Organized files using the `mv` command.
- Located files using the `find` command.
- Inspected running processes and identified process IDs (PIDs).

 Commands Practiced

| Command | Purpose |
|---|---|
| mkdir | Create directories |
| cd | Navigate directories |
| touch | Create files |
| echo | Write text |
| cat | Display file contents |
| mv | Move files |
| find | Search for files |
| ls | List files and directories |
| ps | Display running processes |
| pgrep | Find processes by name |
